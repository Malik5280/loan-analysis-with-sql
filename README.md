# Bank Loan SQL Analysis

## Tools Used
- SQLite
- DB Browser for SQLite
- SQL Queries

## Analysis Performed
1. Total Loans Count
2. Loan Status Breakdown
3. Gender Analysis
4. Education vs Average Loan
5. Default by Loan Terms
6. Age Group Analysis
7. Default Rate %
8. Gender + Status Combined
9. Average Age of Defaulters vs Paid Off

## Key Insights
- Total Loans: 500
- Default Rate: 20%
- 30-day terms had highest defaults
- Most borrowers aged 25-35
